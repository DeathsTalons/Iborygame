Ibory 隐私政策

自2026年10月26日起生效

本页为英文版本的翻译。如有任何出入，以英文版本为准。

简而言之：Ibory 没有广告、没有数据分析、没有追踪，也绝不会出售任何关于你的信息。单人游戏无需账号，所有数据都保存在你的设备上。如果你注册账号，服务器只保存云存档、排行榜、聊天和联盟所需的数据，你随时可以全部删除。

谁在运营 Ibory

Ibory 是一款免费游戏，由一位独立开发者制作和运营。关于你的数据，如有疑问、请求或投诉，请发邮件至 iboryfree@gmail.com，或在 Ibory Discord 上联系管理员。

不注册账号游玩

你的游戏保存在你自己设备的浏览器存储中。除非你自己决定——注册账号、保存存档文件或复制存档代码——否则它不会被发送到任何地方。

注册账号后服务器保存的内容

内容用途保存多久
用户名和游戏内名字你在 Ibory 各处的名字：排行榜、聊天、联盟和报告。直到你删除账号
密码登录。只保存加盐的单向哈希值，任何人都无法读取你的密码。直到你删除账号
云存档（最新存档和一份较早的副本）在新设备上找回游戏，并在存档出错时帮你恢复。直到你删除账号
每小时的游戏快照（部队、资源、声望等数字）检测作弊。异常情况会被标记，交由人工审核；不会自动封禁任何人。14天；标记保存90天
排行榜数据公开的排行榜。直到你退出排行榜或删除账号
你上传的头像、头像框和英雄图片展示给其他玩家。直到你移除它们或删除账号
世界频道和联盟聊天的消息与表情回应展示给其他玩家。世界频道保留最近1000条，每个联盟保留最近500条；你的消息会随账号一起删除
私信投递消息。管理员可以查看私信，以处理滥用和举报。30天
聊天中发送的图片在聊天中显示。14天
联盟、入侵、PvP、交易和商店记录让这些功能正常运行，并监控滥用行为。直到你删除账号（已结束的对局和交易记录会保留你当时的名字）
你提交的举报或针对你的举报社区管理。直到管理员结案；你提交的举报会随账号一起删除
手机通知订阅发送你开启的集结、消息和游戏通知。直到你关闭通知、在所有设备上退出或删除账号
你连接的 IP 地址拦截反复输错密码的尝试。约一小时
你选择分享的战报，附带你 IP 地址的加密形式（单向哈希）让持有链接的人查看战报，并限制每个连接每小时可分享的战报数量。自最后一次分享起30天，之后删除

Ibory 绝不会要求你提供真实姓名、电子邮箱、电话号码、位置、通讯录或支付信息。

还有哪些服务参与

  • Cloudflare 运行游戏服务器并保存上述数据。为运营和保护其网络，它可能会短期保留技术日志，例如 IP 地址。
  • GitHub Pages 托管游戏文件，你的设备下载这些文件时它会看到你的 IP 地址。
  • Google Fonts 提供游戏字体，因此你的设备会向 Google 服务器请求字体。
  • Giphy 提供 GIF 搜索。你的搜索词经由 Ibory 服务器转发（不与你关联），GIF 从 Giphy 的服务器加载。
  • 你手机的推送服务（Android 上为 Google 的服务）负责投递你开启的通知。
  • 其他玩家在聊天中链接的图片，可能会从其所在网站加载。

除法律要求外，不会与任何其他人分享任何内容。

其他玩家能看到什么

你的游戏内名字、头像和头像框、英雄图片、排行榜数据、所在联盟，以及你在世界频道或联盟聊天中发的所有内容。私信只有你、对方玩家和管理员能看到。

你的选择

  • 删除账号：在游戏中（设置 → 账号与云存档 → 删除账号）或在网页 iborygame.com/account 上操作。上述与你账号关联的所有内容会立即删除。你设备上的游戏不受影响。
  • 随时在游戏中退出排行榜、移除你的图片或关闭通知。
  • 屏蔽玩家，使其私信无法发送给你；也可以向管理员举报消息或玩家。
  • 通过上方的联系方式，索取你的云存档副本或任何与你数据有关的信息。

儿童

Ibory 不面向13岁以下儿童，也不会有意收集他们的信息。如果你认为有13岁以下的儿童注册了账号，请联系管理员，该账号将被删除。

安全

所有流量均经过加密（HTTPS）。密码以哈希形式保存，反复失败的登录尝试会被拦截。没有任何系统是绝对安全的，所以请使用一个你在其他地方都没用过的密码。

变更

如果本政策有变，新版本会以新的日期发布在这里，重大变更会在游戏的 Discord 上公告。
