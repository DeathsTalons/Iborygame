Ibory アカウント

アカウントは Ibory 全体でのあなたの名前であり、ゲームのコピーをオンラインに保存します。ほとんどの操作はゲーム内の設定 → アカウントとクラウドセーブで行えます。

アカウント作成・ログイン

ゲームを開き、設定 → アカウントとクラウドセーブ で、ユーザー名とパスワードを決めてください。新しい端末で同じ情報でログインすれば、最新のセーブが戻ってきます。

ゲーム内の名前を変える

ゲーム内の 設定 → あなたの名前 から変更できます。初回は無料、その後は30日に1回です。ログイン用のユーザー名は変わりません。

スマホをなくした、または誰かがログインしているかも？

どの端末でもいいのでログインし、設定 → アカウントとクラウドセーブ で他の端末からログアウトをタップしてください。他のすべての端末がログアウトされ、通知も届かなくなります。

パスワードを忘れた？

プレイしている端末から、Ibory の Discord で管理者に連絡するか、iboryfree@gmail.com にメールしてください。

アカウントを削除

ゲーム内（設定 → アカウントとクラウドセーブ → アカウントを削除）でも、このページでも削除できます。次のものが直ちに完全に削除されます：

  • 2つのクラウドセーブ
  • ランキングの記録、プロフィール画像、フレーム、英雄の画像
  • ワールドチャット・同盟チャットの発言、個人メッセージ、リアクション、チャット画像
  • 同盟への所属（盟主だった場合は次のメンバーが引き継ぎます）、侵攻、戦功章、見た目アイテム
  • スマホ通知と、あなたが送った通報

終了した対戦や取引の記録には、当時の名前が残ります。端末に保存されたゲームには影響せず、この操作は取り消せません。サーバーが保存するすべての内容はプライバシーポリシーをご覧ください。

ログインできない場合は、Discord かメール（上記）で連絡してください。代わりに削除します。
