Ibory プライバシーポリシー

2026年10月26日施行

このページは英語版の翻訳です。内容に相違がある場合は英語版が優先されます。

要点：Ibory には広告も、アクセス解析も、トラッキングもありません。あなたに関する情報を売ることも決してありません。シングルプレイにアカウントは不要で、データはすべて端末に保存されます。アカウントを作った場合、サーバーはクラウドセーブ、ランキング、チャット、同盟に必要なものだけを保存し、いつでもすべて削除できます。

運営者

Ibory は、ひとりの個人開発者が制作・運営する無料ゲームです。データに関する質問、依頼、苦情は iboryfree@gmail.com にメールするか、Ibory の Discord で管理者に連絡してください。

アカウントなしで遊ぶ場合

ゲームはあなたの端末のブラウザストレージに保存されます。アカウントを作る、セーブファイルを保存する、セーブコードをコピーするなど、あなた自身が決めない限り、どこにも送信されません。

アカウントを作った場合にサーバーが保存するもの

内容目的保存期間
ユーザー名とゲーム内の名前Ibory 全体でのあなたの名前：ランキング、チャット、同盟、レポート。アカウント削除まで
パスワードログイン。ソルト付きの一方向ハッシュだけを保存するため、誰もパスワードを読めません。アカウント削除まで
クラウドセーブ（最新のセーブと、ひとつ前のコピー）新しい端末でゲームを取り戻し、セーブに問題が起きたときに助けるため。アカウント削除まで
1時間ごとのゲームのスナップショット（兵数、資源、威信などの数値）不正の検出。異常は人が確認するために記録され、自動でブロックされることはありません。14日間。記録されたフラグは90日間
ランキングの数値公開ランキング。ランキングから外れるか、アカウント削除まで
アップロードしたプロフィール画像、フレーム、英雄の画像他のプレイヤーに表示するため。削除するか、アカウント削除まで
ワールドチャット・同盟チャットのメッセージとリアクション他のプレイヤーに表示するため。ワールドチャットは最新1,000件、各同盟は最新500件を保存。あなたの発言はアカウント削除時に消去
個人メッセージ配信のため。管理者は個人メッセージを読むことができます（迷惑行為や通報への対応のため）。30日間
チャットで送った画像チャットに表示するため。14日間
同盟、侵攻、PvP、取引、ショップの記録これらの機能を動かし、不正を監視するため。アカウント削除まで（終了した対戦と取引の記録には当時の名前が残ります）
あなたが送った通報、あなたへの通報モデレーション。管理者が対応を終えるまで。あなたが送ったものはアカウントと一緒に削除
スマホ通知の購読情報オンにした集結、メッセージ、ゲームの通知を送るため。通知をオフにする、すべての端末からログアウトする、またはアカウント削除まで
接続元の IP アドレスパスワードの誤入力が続く試行をブロックするため。約1時間
共有を選んだ戦闘レポートと、あなたの IP アドレスを暗号化した形（一方向ハッシュ）リンクを知っている人にレポートを表示し、1つの接続が1時間に共有できるレポート数を制限するため。最後に共有されてから30日間。その後削除

Ibory が本名、メールアドレス、電話番号、位置情報、連絡先、支払い情報を求めることはありません。

関わるほかのサービス

  • Cloudflare がゲームサーバーを動かし、上記のデータを保存します。ネットワークの運用と保護のため、IP アドレスなどの技術ログを短期間保持することがあります。
  • GitHub Pages がゲームのファイルを配信し、端末がファイルをダウンロードするときに IP アドレスを受け取ります。
  • Google Fonts がゲームのフォントを提供するため、端末は Google のサーバーにフォントを要求します。
  • Giphy が GIF 検索を提供します。検索語は Ibory のサーバーを経由し（あなたとは結び付けられません）、GIF は Giphy のサーバーから読み込まれます。
  • スマホの通知サービス（Android では Google のサービス）が、オンにした通知を届けます。
  • 他のプレイヤーがチャットにリンクした画像は、その画像があるサイトから読み込まれることがあります。

法律で求められる場合を除き、それ以外の誰とも何も共有しません。

他のプレイヤーに見えるもの

ゲーム内の名前、プロフィール画像とフレーム、英雄の画像、ランキングの数値、所属同盟、そしてワールドチャットや同盟チャットに書いたすべての内容。個人メッセージを見られるのは、あなた、相手のプレイヤー、管理者だけです。

あなたにできること

  • アカウントの削除：ゲーム内（設定 → アカウントとクラウドセーブ → アカウントを削除）またはウェブの iborygame.com/account から。アカウントに関連する上記のものはすべて直ちに削除されます。端末のゲームには影響しません。
  • ランキングからの離脱、画像の削除、通知のオフはゲーム内でいつでもできます。
  • プレイヤーをブロックすると、その人の個人メッセージは届かなくなります。メッセージやプレイヤーを管理者に通報することもできます。
  • クラウドセーブのコピーや、データに関するその他の情報は、上記の連絡先で依頼できます。

子ども

Ibory は13歳未満を対象としておらず、13歳未満の情報を意図して収集することはありません。13歳未満の子どもがアカウントを作ったと思われる場合は管理者に連絡してください。アカウントを削除します。

セキュリティ

通信はすべて暗号化されています（HTTPS）。パスワードはハッシュとして保存され、失敗が続くログイン試行はブロックされます。完全に安全なシステムはないため、他では使っていないパスワードを使ってください。

変更

このポリシーが変わった場合、新しい日付とともにここに掲載し、重要な変更はゲームの Discord でお知らせします。
