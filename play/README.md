# Ibory

A slow, punishing, real-time medieval strategy game set in the fallen kingdom. Build cities, raise heroes, farm valleys and siege historic cities, alone or with an alliance.

Version 0.2.8

Play in English, Spanish, Vietnamese, Russian, Chinese, Japanese, Korean or Arabic (Settings, Language). / Juega en español: Ajustes, Idioma. / Chơi bằng tiếng Việt: Cài Đặt, Ngôn ngữ. / Играй на русском: Настройки, Язык. / 中文：设置 → 语言 / 繁體中文：設定 → 語言。 / 日本語：設定 → 言語。 / 한국어: 설정 → 언어. / العب بالعربية: الإعدادات، اللغة.
