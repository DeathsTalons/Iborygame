Ibory 隱私政策

自2026年10月26日起生效

本頁為英文版本的翻譯。如有任何出入，以英文版本為準。

簡而言之：Ibory 沒有廣告、沒有資料分析、沒有追蹤，也絕不會出售任何關於你的資訊。單人遊戲無需帳號，所有資料都儲存在你的裝置上。如果你註冊帳號，伺服器只儲存雲端存檔、排行榜、聊天和聯盟所需的資料，你隨時可以全部刪除。

誰在運營 Ibory

Ibory 是一款免費遊戲，由一位獨立開發者製作和運營。關於你的資料，如有疑問、請求或投訴，請發郵件至 iboryfree@gmail.com，或在 Ibory Discord 上聯絡管理員。

不註冊帳號遊玩

你的遊戲儲存在你自己裝置的瀏覽器儲存中。除非你自己決定——註冊帳號、儲存存檔檔案或複製存檔程式碼——否則它不會被髮送到任何地方。

註冊帳號後伺服器儲存的內容

內容用途儲存多久
使用者名稱和遊戲內名字你在 Ibory 各處的名字：排行榜、聊天、聯盟和報告。直到你刪除帳號
密碼登入。只儲存加鹽的單向雜湊值，任何人都無法讀取你的密碼。直到你刪除帳號
雲端存檔（最新存檔和一份較早的副本）在新裝置上找回遊戲，並在存檔出錯時幫你恢復。直到你刪除帳號
每小時的遊戲快照（部隊、資源、聲望等數字）檢測作弊。異常情況會被標記，交由人工稽核；不會自動封禁任何人。14天；標記儲存90天
排行榜資料公開的排行榜。直到你退出排行榜或刪除帳號
你上傳的頭像、頭像框和英雄圖片展示給其他玩家。直到你移除它們或刪除帳號
世界頻道和聯盟聊天的訊息與表情回應展示給其他玩家。世界頻道保留最近1000條，每個聯盟保留最近500條；你的訊息會隨帳號一起刪除
私訊投遞訊息。管理員可以檢視私訊，以處理濫用和檢舉。30天
聊天中傳送的圖片在聊天中顯示。14天
聯盟、入侵、PvP、交易和商店記錄讓這些功能正常執行，並監控濫用行為。直到你刪除帳號（已結束的對局和交易記錄會保留你當時的名字）
你提交的檢舉或針對你的檢舉社群管理。直到管理員結案；你提交的檢舉會隨帳號一起刪除
手機通知訂閱傳送你開啟的集結、訊息和遊戲通知。直到你關閉通知、在所有裝置上退出或刪除帳號
你連線的 IP 地址攔截反覆輸錯密碼的嘗試。約一小時
你選擇分享的戰報，附帶你 IP 地址的加密形式（單向雜湊）讓持有連結的人檢視戰報，並限制每個連線每小時可分享的戰報數量。自最後一次分享起30天，之後刪除

Ibory 絕不會要求你提供真實姓名、電子郵箱、電話號碼、位置、通訊錄或支付資訊。

還有哪些服務參與

  • Cloudflare 執行遊戲伺服器並儲存上述資料。為運營和保護其網路，它可能會短期保留技術日誌，例如 IP 地址。
  • GitHub Pages 託管遊戲檔案，你的裝置下載這些檔案時它會看到你的 IP 地址。
  • Google Fonts 提供遊戲字型，因此你的裝置會向 Google 伺服器請求字型。
  • Giphy 提供 GIF 搜尋。你的搜尋詞經由 Ibory 伺服器轉發（不與你關聯），GIF 從 Giphy 的伺服器載入。
  • 你手機的推送服務（Android 上為 Google 的服務）負責投遞你開啟的通知。
  • 其他玩家在聊天中連結的圖片，可能會從其所在網站載入。

除法律要求外，不會與任何其他人分享任何內容。

其他玩家能看到什麼

你的遊戲內名字、頭像和頭像框、英雄圖片、排行榜資料、所在聯盟，以及你在世界頻道或聯盟聊天中發的所有內容。私訊只有你、對方玩家和管理員能看到。

你的選擇

  • 刪除帳號：在遊戲中（設定 → 帳號與雲端存檔 → 刪除帳號）或在網頁 iborygame.com/account 上操作。上述與你帳號關聯的所有內容會立即刪除。你裝置上的遊戲不受影響。
  • 隨時在遊戲中退出排行榜、移除你的圖片或關閉通知。
  • 遮蔽玩家，使其私訊無法傳送給你；也可以向管理員檢舉訊息或玩家。
  • 透過上方的聯絡方式，索取你的雲端存檔副本或任何與你資料有關的資訊。

兒童

Ibory 不面向13歲以下兒童，也不會有意收集他們的資訊。如果你認為有13歲以下的兒童註冊了帳號，請聯絡管理員，該帳號將被刪除。

安全

所有流量均經過加密（HTTPS）。密碼以雜湊形式儲存，反覆失敗的登入嘗試會被攔截。沒有任何系統是絕對安全的，所以請使用一個你在其他地方都沒用過的密碼。

變更

如果本政策有變，新版本會以新的日期釋出在這裡，重大變更會在遊戲的 Discord 上公告。
